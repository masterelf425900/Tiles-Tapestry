× Help & Shortcuts
Canvas
  • Drag empty space to pan · scroll wheel to zoom
  • Drag an image to move it
  • Drop on another image to swap positions & sizes
  • Drop on empty space to snap to nearby edges
  • Ctrl/Cmd+Click images to multi-select
Keyboard
  • Arrow keys — nudge selected image (Shift = 10px)
  • Delete / Backspace — remove selected
  • Ctrl+Z / Ctrl+Shift+Z — undo / redo
  • Ctrl+A — select all images
  • Esc — close dialogs / clear selection
Files
  • Drag image files onto the canvas to add them
Notes
  • Swapping or dropping an image locks it in place. Set L to "No" on it later if you want it to rejoin auto-flow.
  • Mosaic grid mode (in Resize Canvas) is for collages built from a repeating "small" cell, where long/wide/big tiles are 1×2, 2×1 and 2×2 of that cell. It rebuilds every tile's size & position from your cell size so the grid tiles the new resolution exactly, with no leftover gap. Give it your small cell's W×H (the Copy button grabs it from the selected image).
